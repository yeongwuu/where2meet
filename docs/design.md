## 1. 디자인 방향
**"같이 가는 사람들을 배려하는, 차분하고 믿음직한 사내 도구."**
막내·총무가 여러 사람의 취향을 대신 챙기는 부담을 덜어주는 앱이에요. 화려한 맛집 앱이 아니라, **근거를 보여주고 안심시키는** 화면이 목표예요.

| 키워드 | 화면에서의 의미 |
|---|---|
| 배려 | 못 먹는 것은 가장 위, 가장 눈에 띄게. 누가 못 먹는지는 숨기고 "1명"으로만 |
| 근거 | 추천마다 "왜 이 사람들에게 맞는지" ✓, "확인할 점" ⚠를 함께 |
| 빠름 | 입력은 사람 고르기 + 모임 정보뿐. 음식·분위기는 묻지 않고 프로필에서 계산 |
| 안심 | 경고는 빨강 대신 차분한 갈색(`caution`), 과장 표현 없음 |
| 사내감 | PwC 오렌지는 포인트로만, 바탕은 따뜻한 회색 |

## 2. 디자인 토큰

### 2-1. 컬러
| 토큰 | 값 | 용도 |
|---|---|---|
| `primary` | `#D04A02` | 주요 버튼, 선택 칩, 진행 단계, 활성 탭, 1순위 추천 카드 테두리. 흰 글씨 대비 6.0:1 |
| `primary-pressed` | `#A93C02` | 버튼 눌림, 연주황 바탕 위 글씨 |
| `primary-soft` | `#FDF1EA` | 선택 요약 칩 바탕, "n명이 좋아하는 음식" 박스, 배지 바탕 |
| `primary-mid` | `#F0A577` | 비율 막대의 가운데 구간 (글씨에 쓰지 않음) |
| `star` | `#FFB600` | 별점 아이콘만 |
| `ink` | `#1F1F1F` | 타이틀, 식당명, 이름 |
| `text` | `#3D3D3D` | 본문, 후기, 근거 문장 |
| `text-sub` | `#6E6E6E` | 메타 정보, 안내문, 미선택 칩 글씨 (흰 바탕 4.9:1) |
| `text-disabled` | `#B5B5B5` | 비활성에만 |
| `bg` | `#FFFFFF` | 카드·화면·바텀시트 |
| `bg-subtle` | `#F6F5F3` | 카드 목록 화면 바탕, 이미지 자리, 근거 태그, 안내 박스 |
| `border` | `#E6E3DF` | 카드·칩·입력창 테두리, 구분선, 막대 빈 구간 |
| `check` | `#2E7D4F` | ✓ 맞춘 조건, "취향 입력 완료", 기준 체크리스트 테두리 |
| `caution` | `#9A5B13` | ⚠ 확인할 점, "반드시 피할 것", "취향 미입력", 오래된 정보 |
| `danger` | `#C62828` | 입력 오류 문구에만 |

**규칙**
- 주황은 한 화면에 **주요 버튼 1개 + 선택된 칩 + 강조 카드 1개**까지.
- `check`(초록)와 `caution`(갈색)은 **항상 아이콘(✓ / ⚠)과 함께** 써요. 색만으로 구분하지 않아요.
- 빨강(`danger`)은 "못 먹는 것"에도 쓰지 않아요. 경고처럼 보이면 사용자가 불안해해요.

- 간격 4px 단위: `4 / 8 / 12 / 16 / 20 / 24 / 32`
- 화면 좌우 여백 20px · 카드 사이 12px · 카드 안 요소 사이 12px · 칩 사이 8px
- 모서리: 칩·배지·스위치 `999px` · 썸네일·안내 박스 `8px` · 버튼·입력창 `10px` · 카드 `12px` · 바텀시트 상단 `16px`
- 그림자
  - `shadow-card`: `0 1px 2px rgba(31,31,31,0.04), 0 4px 12px rgba(31,31,31,0.06)` — 추천 카드, 식당 카드
  - `shadow-cta`: `0 -4px 12px rgba(31,31,31,0.06)` — 하단 고정 버튼 영역 윗면
  - 일반 정보 카드는 그림자 없이 테두리만

## 4. 아이콘 · 이미지 · 폰트
- 아이콘: **Lucide** (ISC, 상업적 이용 가능), 선 두께 1.75(체크는 2.25), 크기 14~22px. 쓰는 아이콘: home, users, book-open, user, chevron-left/right/down/up, search, plus, check, triangle-alert, lock, sparkles, heart, copy, utensils, star
- 이모지는 화면에 쓰지 않아요. 이 문서의 ✓ · ⚠ · ✦ 기호는 각각 Lucide `check` · `triangle-alert` · `sparkles` 아이콘을 뜻해요
- 이미지: 식당 실사진·다른 서비스 캡처 사용 금지 → 썸네일 블록 또는 AI 생성 이미지만
- 폰트: Pretendard만 (상업적 이용 가능 확인됨)

## 5. 화면별 구성 — 5페이지
> 위에서 아래 순서 = 화면에 놓이는 순서. 데이터 필드는 `data_spec.md` 참고

### 5-1. 페이지 구성
| 페이지 | 구성 순서 | 하단 | 동작 (목업에서 재생 가능) |
|---|---|---|---|
| **① 시작하기** (가입 + 내 취향) | 서비스 배지 → 앱 이름 → 한 줄 소개 → **체험 계정으로 바로 시작** 카드 → 1 기본 정보(초대코드·닉네임·직급) → 2 못 먹는 것(필수) → 3 음식 취향(좋아함·별로) → 4 회식 스타일(술·분위기) → 가상 데이터 안내 | CTA "저장하고 모임 만들기" | 체험 계정 카드 → ②로 바로 이동 |
| **② 모임 만들기** (홈 역할) | 인사 + 제목 → 이어서 하기 한 줄 → **같이 갈 사람** 카드(검색 → 접히는 팀 그룹 → 비회원 목록 + 추가) → **모임 정보** 카드(목적 → 예산 슬라이더 → 언제 → 어디서 → "음식·분위기는 묻지 않아요" 안내) | CTA 바 "총 12명 · 임원 1 · 상사 2 · 취향 모름 2" + "취향 종합 보기" → 하단 탭(모임) | 팀 펼치기/접기, 예산 슬라이더·빠른 선택 칩 |
| **③ 취향 종합** ⭐ | 헤더 + 모임 요약 부제 → 통계 타일 3개 → **반드시 피할 것**(주의 카드, 끌 수 없음, 이름 숨김) → 모임 성격 → 다 같이 좋아하는 음식(막대 + 별로 안내) → 술·분위기(비율 막대 + 결론) → 취향 모름 n명(입력 요청). 반드시 피할 것을 뺀 카드는 스위치로 반영 끄기 | CTA "✦ 이 조건으로 추천받기" | — |
| **④ 추천 결과** (상세·확정 포함) | 헤더 + 조건 고치기 → AI 요약 박스 → **아코디언 추천 카드 3개**(1순위 펼침) → "조건을 지키는 곳 n곳 · 더 보기" → 알레르기 재확인 안내 | 하단 탭(모임) | 카드 펼치기/접기(한 번에 하나), 확정 → ⑤ |
| **⑤ 사람·기록** (후기 + 비회원 메모) | 헤더 + 비회원 추가 → **지난 모임 후기** 인라인 카드 → 비회원 메모 제목 + 자물쇠 안내 → 비회원 메모 카드 목록 | 하단 탭(사람) | 후기 올리기 → 후기 카드가 완료 문구로 바뀌고, 상무님 메모 기록 줄이 하이라이트 |

### 5-2. v2(10화면) → v3(5페이지) 바뀐 점
| v2 화면 | v3 위치 | 바뀐 점 |
|---|---|---|
| P0 가입 + P1 내 취향 | ① 시작하기 | 한 화면으로 합치고 "체험 계정으로 바로 시작" 추가 (심사위원은 입력 없이 진행) |
| P2 홈 | ② 상단 | 홈 화면 삭제. 진행 중 모임은 "이어서 하기" 한 줄로 |
| P3 사람 선택 + P4 모임 정보 | ② 모임 만들기 | 한 화면, 단계 표시 삭제. 팀은 접어서 스크롤 단축 |
| P5 취향 종합 | ③ | 거의 그대로. "피하면 좋은 것" 카드는 음식 카드 안내 문구로 흡수 |
| P6 추천 + P7 상세·확정 | ④ | 상세 페이지 삭제, 아코디언 카드 안에서 체크·후기·확정 |
| P8 후기 + P9 사람 | ⑤ | 한 화면. 후기를 올리면 아래 메모가 바로 갱신되는 게 보임 |
| 하단 탭 4개 | 3개 | 홈 탭 삭제 → 모임 · 사람 · 내 취향 |

### 5-3. 데모 흐름 (1~2분 영상 기준)
① 체험 계정으로 시작 → ② 팀 전체가 체크된 상태에서 목적 "팀 회식"만 확인 → ③ 취향 종합 확인 → ④ 산채정 펼쳐서 확정 → ⑤ 후기 올리면 상무님 메모 갱신
→ 무대 문구 **"버튼 3번이면 끝"** = 사람 체크 → 취향 종합 확인 → 추천받기

## 9. Claude Design 프롬프트 템플릿

**① 디자인 시스템 만들기 (토큰 txt 첨부)**
```
첨부한 design_tokens.txt로 디자인 시스템을 먼저 만들어줘.
컬러·글꼴(Pretendard)·간격·모서리·그림자를 토큰으로 정리하고,
버튼·선택 칩·근거 태그·상태 배지·카드(기본/주의/입력/추천)·하단 탭(3칸) 미리보기를 보여줘.
카드는 흰 배경에 회색 테두리가 기본이고, 강조할 때만 주황 테두리와 그림자를 써줘.
```

**② 화면 입히기 (목업 캡처 ①~⑤ 첨부)**
```
첨부한 목업 캡처 5장을 방금 만든 디자인 시스템으로 다시 만들어줘.
화면 폭 390px 모바일 기준이고, 페이지별 구성 순서와 동작은 design.md 5장을 따라줘.
특히 ②의 팀 목록 접기, ④의 아코디언 추천 카드(한 번에 하나만 펼침), ⑤의 후기 올리기 → 메모 하이라이트는 실제로 동작하게 해줘.
샘플 데이터는 members.json, guests.json, restaurants.json, reviews.json의 가상 데이터를 써줘.
```

**③ 수정 (페이지 단위 · 유지할 것 / 바꿀 것)**
```
④ 추천 결과
- 유지: 카드 3개, ✓/⚠ 목록, 1순위 주황 테두리와 처음부터 펼친 상태
- 바꿀 것: 펼친 카드 안 후기는 1개만, 카드 그림자를 지금보다 연하게
```
